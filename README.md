# CodeAlpha Stock Market Project 📈

## About the Project

This is a simple **Stock Market Portfolio** that I created as part of my **CodeAlpha Internship**.

I made this project using Python to practice dictionaries, user input, calculations, conditions, and file handling.

The program allows the user to select a stock, enter the quantity they want to buy, and calculate the total investment.
